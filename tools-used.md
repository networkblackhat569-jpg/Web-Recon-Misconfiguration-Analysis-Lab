# Tools Used

## 🔧 dig

Used for DNS enumeration and resolving A records and subdomains.

Example:

```
dig chhipa.org
dig www.chhipa.org
```

---

## 🔧 curl

Used for HTTP header inspection and response analysis.

Example:

```
curl -I https://example.com
```

---

## 🔧 httpx

Used for probing web services and checking response status codes.

Example:

```
httpx -u https://example.com
```

---

## 🔧 nmap

Used for basic port scanning and service detection.

Example:

```
nmap -sV example.com
```
